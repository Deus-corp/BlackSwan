Appendix L: Configuration Files (Reference Configurations)¶

Purpose: Contains the reference configuration files that control the behavior of the Black Swan system. Includes the unified global_policy.json, as well as profile configurations for Fast Path, Meat Canary, Dynamic Routing, and Evolution. All parameters mentioned in the documentation are gathered here.
