# Исходный код Black Swan

Здесь будет располагаться production-код системы.  
Текущая структура:

- `core/` – базовые структуры данных и шина событий (GlobalState, EventBus).
- `comm/` – сетевое взаимодействие, gossip, консенсус (будет добавлено).
- `economy/` – экономический контур, ROI Dispatcher, PPO-исполнители.
- `memory/` – иерархическая память Mem0g, CRDT-синхронизация.
- `security/` – LastBreath, Sting, изоляция, аппаратный watchdog.

Весь код должен следовать принципам Formal Verification First: критические инварианты описываются в TLA+ до реализации.
