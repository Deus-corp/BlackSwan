## J3. Источники закупки (Рекомендации)

- **GPU, CPU, материнская плата:** Новые через официальные каналы (Amazon Business, B&H Photo). Б/у не рекомендуется из-за риска деградации PUF.
- **RAM, NVMe:** Официальные ресселеры, обязательная проверка ECC.
- **UPS:** APC Authorized Resellers. Только Online Double-Conversion.
- **Arduino, PiKVM, реле:** Любые проверенные поставщики.

---

## J4. Процедура приёмки

1. **Визуальный осмотр** на предмет повреждений.
2. **Проверка серийных номеров** (GPU, CPU) на соответствие заказу.
3. **Запуск `hw_probe`** для верификации заявленных характеристик.
4. **Тепловой стресс-тест (30 мин)** — температура всех GPU ≤ 85 °C.
5. **Регистрация PUF** — первый холодный старт для записи SRAM-энтропии.
6. **Генерация `readiness_manifest.json`** (см. [Hardware_Isolation.md](hardware_isolation.md)).
