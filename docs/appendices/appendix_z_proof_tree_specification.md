# Appendix Z — Proof Tree Specification
## Z.1. Назначение
Определение формата и правил валидации деревьев логического вывода,
Используемых в Constitutional Debate 2.0 для доказательства
Совместимости предлагаемых L3.1‑инвариантов с L3.0‑аксиомами.
## Z.2. Структура Proof Tree
Дерево представляется в виде JSON‑объекта с рекурсивной структурой.
### Z.2.1. Узел дерева
| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `node_id` | string | Уникальный идентификатор узла |
| `statement` | string | Логическое утверждение (в SMT‑LIB2 или естественном языке) |
| `rule` | string | Применённое правило вывода (например, `modus_ponens`, `forall_intro`) |
| `children` | array[string] | Список `node_id` дочерних узлов, на которых основан вывод |
| `z3_verified` | boolean | Флаг успешной верификации узла через Z3 |
| `z3_model` | object | (Опционально) модель Z3, подтверждающая утверждение |
### Z.2.2. Корневой узел
Корневой узел содержит итоговое утверждение, которое требуется доказать.
Все листья должны быть либо аксиомами L3.0, либо ранее доказанными
Леммами из Mem0g L2.
## Z.3. Правила вывода
Поддерживаемые правила (минимальный набор):
| Правило | Описание |
| :--- | :--- |
| `axiom` | Утверждение является аксиомой L3.0 |
| `modus_ponens` | Из A и A → B выводится B|
| `forall_intro` | Введение квантора всеобщности |
| `exists_elim` | Удаление квантора существования |
| `conj_intro` | Введение конъюнкции |
| `disj_elim` | Удаление дизъюнкции |
| `lemma` | Ссылка на ранее доказанную лемму (CID) |
## Z.4. Валидация дерева
1.Проверка структурной целостности: все `children` ссылаются на
Существующие узлы, нет циклов.
2.Для каждого узла проверяется, что его `statement` логически следует
Из `statements` дочерних узлов по указанному `rule`.
3. Multi‑Solver (Z3, CVC4, Yices) подтверждает логическое следование.
4. Concolic Filtering проверяет, что утверждение не является
Тривиальной тавтологией.
## Z.5. Хранение
Деревья сохраняются в IPFS как артефакты типа `ProofTree`. Ссылка на
Дерево включается в `ConstitutionalPrinciple` в Mem0g L2.
