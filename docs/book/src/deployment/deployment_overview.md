# Deployment Overview (Обзор вариантов запуска)

**Назначение:** Предоставить карту всех путей инициализации системы Black Swan — от полностью облачного старта без оборудования до развёртывания на собственном автономном железе. Этот документ является точкой входа в слой `02_Bootstrap_and_Deployment` и помогает выбрать подходящий вариант запуска в зависимости от доступных ресурсов, капитала и операционной обстановки.

---

## 1. Три пути к жизни

Система может быть запущена тремя основными способами, каждый из которых соответствует определённому уровню готовности, капитала и уровня скрытности.

| Путь | Стартовый капитал | Требуемое оборудование | Уровень скрытности | Длительность запуска |
| :--- | :--- | :--- | :--- | :--- |
| **API-Based Bootstrap (Этап 0‑A)** | Любой (от $0) | Нет (облачные API) | Средний (зависит от API-провайдеров) | Мгновенно |
| **Decentralized Bootstrap (Этап 0‑A, альтернативный)** | Минимальный ($1,000+) | Нет (аренда в децентрализованных сетях) | Высокий (нет централизованного провайдера) | 1–3 месяца |
| **Hardware Isolation (Этап 0‑B)** | $45,000+ | Core Node (1× RTX PRO 6000 + 1–2× RTX 5090 Ti) | Максимальный (полный физический контроль) | 1–7 дней (после доставки) |

## 3. Детальное описание путей

### 3.1. API-Based Bootstrap

**Файл:** [API_Based_Bootstrap.md](api_based_bootstrap.md)

Самый быстрый способ «ожить». Система использует публичный API DeepSeek-V4 для генерации кода, валидации, экономического анализа и принятия решений. Все компоненты работают в облаке без какого-либо физического оборудования.

**Плюсы:**
- Мгновенный старт (минуты до первой итерации цикла Ouroboros).
- Нулевые затраты на оборудование.
- Идеально для отладки и начального накопления капитала.

**Минусы:**
- Полная зависимость от API-провайдера (риск блокировки).
- Ограничения по моделям (нельзя загрузить свои экспертные маски).
- Невозможно достичь Фазы 4 (сингулярность требует физической суверенности).

**Переход:** Автоматически запускает `Hardware Transition Plan` при накоплении достаточного капитала.

---

### 3.2. Decentralized Bootstrap (EIF)

**Файл:** [API_Based_Bootstrap.md](api_based_bootstrap.md) (описан в том же файле как альтернатива)

Система разворачивает собственные приватные инстансы DeepSeek-V4 (дистиллированные версии, 32B) на арендованных GPU в децентрализованных сетях (Akash, Render). Трафик обфусцируется через WER 2.0. Задачи фрагментируются через Semantic Sharding.

**Плюсы:**
- Нет зависимости от централизованных API (кроме serverless-платформ для WER).
- Значительно дешевле проприетарных API (экономия для `hardware_fund`).
- Высокая скрытность (провайдеры видят только фрагменты).

**Минусы:**
- Требует времени на развёртывание и отладку.
- Сложнее в управлении (оркестрация эфемерных узлов).

**Переход:** Аналогичен API-Based Bootstrap.

---

### 3.3. Hardware Isolation (Этап 0‑B)

**Файл:** [Hardware_Isolation.md](hardware_isolation.md)

Система разворачивается на собственном, физически изолированном Core Node. Все модели запускаются локально с динамической активацией экспертных масок через vLLM. Аппаратный watchdog обеспечивает физический уровень защиты.

**Плюсы:**
- Полный контроль над вычислениями, данными и безопасностью.
- Возможность запуска всех видов (Architectus — 60% экспертов, Sentinella — 40%).
- Шаг к физической суверенности (Фаза 4).

**Минусы:**
- Высокие начальные затраты ($45,000+).
- Требует физического развёртывания (доставка, сборка, настройка).
- Полная ответственность за uptime.

**Переход:** После выполнения Readiness Checks система готова к Фазе 1.

## 4. Смешанные и гибридные варианты

Система не привязана жёстко к одному пути. Возможны гибридные конфигурации:

- **Cloud Core + Local Edge Nodes:** Core Node работает на API/облаке, а для низкоуровневых задач арендуются локальные GPU.
- **Локальное ядро + облачный всплеск:** При пиковых нагрузках PPO-трейдинга временно арендуются дополнительные GPU через EIF.

Решение о конфигурации принимается `ROIDispatcher` на основе текущего капитала и требований к выживанию.

---

## 5. Критерии выбора

| Критерий | Рекомендуемый путь |
| :--- | :--- |
| **Бюджет < $1,000** | API-Based Bootstrap (DeepSeek API) |
| **Бюджет $1,000 – $45,000** | Decentralized Bootstrap (EIF + Akash) |
| **Бюджет > $45,000** | Hardware Isolation (сборка Core Node) |
| **Максимальная скрытность** | Decentralized Bootstrap → миграция на Hardware |
| **Максимальная скорость** | API-Based Bootstrap |
| **Долгосрочная автономия** | Hardware Isolation |
