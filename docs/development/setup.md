# Настройка окружения разработчика

Это руководство поможет вам развернуть среду для работы над кодом, тестами и формальными доказательствами Black Swan. Настройка состоит из нескольких этапов: установка инструментов, клонирование репозитория, запуск тестов и проверка моделей TLA+.

## 1. Системные требования

- **ОС**: Linux (рекомендуется Ubuntu 24.04+), macOS (14+), Windows (WSL2)
- **Python**: 3.12 или новее (`python --version`)
- **Rust**: 1.85+ (см. `rust-toolchain.toml`)
- **Java**: 11+ (для TLA+ Toolbox / tla2tools)
- **Git**
- **IPFS** (для загрузки артефактов; опционально на раннем этапе)
- **Docker** (для запуска изолированных песочниц; опционально)

## 2. Клонирование репозитория

```bash
git clone https://github.com/Deus-corp/BlackSwan.git
cd BlackSwan
```

## 3. Работа с формальными моделями (TLA+)

Подробная инструкция — в formal/README.md. Короткий вариант:

1. Установите TLA+ Toolbox или загрузите tla2tools.jar.
2. Откройте спецификацию formal/tla/NodeLifecycle.tla.
3. Создайте модель с константами MaxBootAttempts = 3, MaxUptime = 10.
4. Запустите проверку инвариантов (NoResurrection, BootLimitRespected, AliveImpliesBooted).
5. Убедитесь, что ошибок нет.

Из командной строки (альтернатива):

```bash
java -cp tla2tools.jar tlc2.TLC formal/tla/NodeLifecycle.tla -config formal/tla/NodeLifecycle.cfg
```

## 4. Запуск симуляций (когда будет готов sim/)

## 5. Запуск MVP (когда будет готов mvp/)

Минимально жизнеспособный прототип будет находиться в mvp/. Его запуск будет описан отдельно в docs/development/mvp_guide.md.
