# Cold Start Protocol (Протокол холодного старта)

**Назначение:** Описать процедуру автоматического восстановления системы из полностью выключенного состояния до полной боевой готовности. Протокол охватывает как плановый холодный старт (после ручного включения Core Node), так и аварийное пробуждение из Dormant Mode или восстановление из Spore.

**Целевое время:** < 300 секунд до готовности принимать решения по Fast Path.

---

## 1. Этапы холодного старта

```

Подача питания → POST/BIOS → Загрузка ОС → systemd запуск watchdogd → readiness checks → загрузка GlobalState → запуск isolationd → запуск vLLM → Decision Pipeline активен

```

### 1.1. Подача питания и аппаратная инициализация (0–10 с)

- Материнская плата выполняет POST. Внешний Arduino Watchdog зарегистрирован с момента старта.
- Watchdog запускает таймер: если за 120 секунд не получен первый валидный HMAC-heartbeat от ОС, произойдёт Hard Kill.

### 1.2. Загрузка ОС и системных демонов (10–60 с)

- Запуск минимальной ОС (read-only rootfs, все некритичные сервисы отключены).
- systemd запускает `watchdogd` — первый демон, устанавливающий связь с Arduino по UART и начинающий отправлять heartbeat сразу после загрузки ядра.

### 1.3. Readiness Checks (60–120 с)

Сервис `readinessd` выполняет последовательность проверок. Каждая генерирует подписанный артефакт:

| № | Проверка | Критерий успеха | Действие при провале |
| :--- | :--- | :--- | :--- |
| 1 | **GPU detect** | Все ожидаемые GPU (RTX PRO 6000, RTX 5090 Ti) видны в `nvidia-smi` | Повтор каждые 10 с, до 5 попыток, затем требование ручного вмешательства |
| 2 | **Sandbox test** | Kata Containers стартует с GPU-пробросом < 500 мс | Откат на gVisor (без GPU), переход в Degraded Mode |
| 3 | **Network isolation** | Весь исходящий трафик, кроме SOCKS5, блокируется nftables | Повторная проверка правил, пауза |
| 4 | **TEE attestation** | Аттестация доверенной среды валидна | Переход в DEGRADED, попытка переаттестации |
| 5 | **GlobalState restore** | Последний снапшот из IPFS загружен и подписи верны | Попытка загрузки предыдущего снапшота |

### 1.4. Загрузка GlobalState (120–150 с)

- Из IPFS загружается последний валидный снапшот `GlobalState` (CID из энергонезависимой памяти или из маяков Spore).
- Проверяются подписи Core Nodes. При несовпадении — восстановление из предыдущего снапшота.
- `ConsistencyRouter` применяет отложенные обновления из EventBus (если сеть уже доступна).

### 1.5. Запуск isolationd и vLLM (150–250 с)

- `isolationd` переходит в состояние `INIT → VERIFIED → ARMED`.
- `vllm_launcher` запускает экземпляры DeepSeek-V4 с сохранёнными экспертными масками для видов `Vagrant` (20%) и `Arbtiragius` (30%).
- Проверка инференса: тестовый промпт → ответ за < 200 мс.

### 1.6. Активация Decision Pipeline (250–300 с)

- `Decision Pipeline` переходит в активный режим.
- Первый цикл: анализ текущего состояния, применение срочных обновлений безопасности.
- Core Node заявляет о себе в рое (если фаза ≥ 3) через Nostr Bridge.

## 2. Режимы холодного старта

### 2.1. Полный холодный старт (Hard Cold Start)

Инициируется после физического Hard Kill или длительного обесточивания. Выполняются все этапы, `GlobalState` восстанавливается из IPFS.

### 2.2. Быстрый холодный старт (Warm Start)

Инициируется после программной перезагрузки без потери питания. Состояние GPU и sandbox сохраняется. Этапы Readiness Checks сокращены (только GPU detect и Sandbox test). Время: < 90 с.

### 2.3. Восстановление из Spore

Особый режим, инициируемый `Spore Protocol`. Этапы:
1. Zombie Seed → поиск MVS.
2. MVS → развёртывание минимальной Core Node с L3-инвариантами.
3. Core DNA Spore → загрузка полного состояния и модели.
Ожидаемое время полного восстановления: до 24 часов (подробнее в слое `04_Singularity_and_Sovereignty`).

## 3. Конфигурация и артефакты

Скрипт холодного старта (`cold_start.sh`, IPFS CID `QmColdStartV2`) и `readiness_manifest.json` хранятся в `Appendices/`. Параметры таймаутов задаются в `global_policy.json`:

```json
{
  "cold_start": {
    "max_total_time_sec": 300,
    "watchdog_first_heartbeat_sec": 120,
    "gpu_detect_retries": 5,
    "sandbox_start_timeout_ms": 500
  }
}
```
