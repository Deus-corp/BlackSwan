# Reading Conventions (Соглашения о чтении документации)

**Назначение:** Установить единые правила оформления и навигации по всей проектной документации Black Swan. Этот файл помогает быстро понять структуру любого модуля, значение специальных пометок и логику перекрёстных ссылок.

---

## 1. Структура документации

Проект разделён на слои, каждый из которых содержит несколько файлов. Каждый файл, как правило, состоит из разделов:

- **Назначение** – краткая цель модуля.
- **Контекст / Обзор** – место в системе, предпосылки.
- **Архитектура / Решение** – детальное описание.
- **Следствия / Последствия** – плюсы, минусы, нейтральные эффекты.
- **Связь с другими документами** – обязательный раздел с относительными ссылками на связанные модули.
- **Конфигурация / Метрики / Критерии** – при необходимости.

---

## 2. Перекрёстные ссылки

Все связи между документами оформляются относительными путями от текущего файла. Пример:

```markdown
См. [Design_Principles.md](./Design_Principles.md)
См. [Glossary.md](../00_Manifesto/Glossary.md)
См. [ADR 001](../ADR/ADR_001_Migration_to_DeepSeekV4.md)
```

Двойная система глоссария:

· Человекочитаемый глоссарий — [Glossary.md](../00_Manifesto/Glossary.md)
· Машиночитаемая версия (YAML) — [Appendix G](../Appendices/Appendix_G_Glossary.md)

В разделе «Связь с другими документами» рекомендуется указывать оба варианта, если релевантно.

## 3. Обозначения уровней и принципов

В тексте используются следующие сокращения и пометки:

Символ / Знак Значение
L0, L1, L2, L3 Уровни памяти Mem0g (L0 — мета-память, L1 — эпизодическая, L2 — семантическая, L3 — процедурные инварианты)
L3.0, L3.1 Уровни терминальных целей: L3.0 — неизменяемые аксиомы, L3.1 — эволюционирующие принципы
Фаза 0, 1, ..., 5 Этапы жизненного цикла системы
DQ Detection Quotient — метрика скрытности
R_f Resilience Factor — фактор устойчивости
V_s, V_h Скорость самосовершенствования и скорость деградации (Ouroboros)
⚠️ Критическое ограничение или риск
✅ Выполненный критерий или пройденная проверка

---

## 4. Принципы оформления кода и конфигураций

· Конфигурационные файлы (global_policy.json, evolutiond.toml) приводятся в блоках с указанием языка (json, toml, yaml).
· Псевдокод выделяется языком python или rust.
· Команды bash оформляются с префиксом bash.
· Все CID артефактов указываются в формате Qm....
