## [2026-05-14] MetaAgent v0.2 – автономный наблюдатель с памятью и управлением

### Новый сервис MetaAgent
- Отдельный контейнер (`meta-agent` в `docker-compose.async.yml`), не торгует.
- Читает heartbeats и сделки из общего `events.jsonl` роя.
- Каждые 100 шагов отправляет полный контекст (капиталы, DQ, ниши, сделки) в локальную LLM и получает структурированный анализ (OBSERVATION, SWARM ASSESSMENT, STRATEGIC ADJUSTMENTS).
- Публикует управляющие команды (`meta_command`) в CRDT для всех узлов.
- Сохраняет свои размышления в `meta_events.jsonl` и загружает память при рестарте.

### Улучшения мутаций
- Усилен парсер JSON в `mutation_engine.py`: удаление XML‑тегов, поиск JSON в ```json блоках и фигурных скобках.
- При полном провале LLM применяется случайная мутация, чтобы рой не стоял на месте.

### Технические детали
- MetaAgent использует только JSONL (без SQLite) для надёжности в контейнерах.
- Команды MetaAgent пока логируются узлами; автоматическое применение будет добавлено в следующей итерации.

## [2026-05-15] Полностью замкнут автономный цикл управления

- **MetaAgent**:
  - Получает heartbeats из общего CRDT (SQLite).
  - Анализирует состояние роя (капиталы, DQ, фитнес, ниши).
  - Генерирует JSON-команды `ADJUST_SWARM` с плавающими параметрами.
  - Публикует их в CRDT.
- **Торговые узлы**:
  - Читают JSON-команды из CRDT.
  - Применяют изменения параметров с математическим демпфированием.
  - Публикуют свои heartbeats в общий CRDT каждые 30 шагов.
- **Мутации**: локальная LLM DeepSeek-R1 генерирует валидный JSON, мутации успешно применяются.
- **Статус**: система полностью автономна, готова к внедрению Watchdog и контролируемого хаоса.

  - Интеграция с Overseer через explorer_heartbeat
