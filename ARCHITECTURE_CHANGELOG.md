# Архитектурный журнал проекта BlackSwan

## [2026-05-12] Начало рефакторинга по плану PR-0 – PR-12
- Принят план декомпозиции node_agent.py (PR-0 – PR-12).
- Заведён этот файл для отслеживания архитектурных решений.

## [2026-05-12] Добавление ордербука в TradingController и контекст мутаций
- **Изменено**: `node_agent.py` (main_loop), `trading_controller.py` (decide_action)
- **Добавлено**: передача `imbalance` и `delta_volume` в параметры решения.
- **Причина**: ордербук теперь влияет на каждую сделку, не только на мутации.
- **Следствия**: контроллер корректирует размер позиции при давлении против тренда.

## [2026-05-12] Интеграция ордербука в торговые решения
- `node_agent.py`: получение imbalance перед каждым `decide_action`.
- `trading_controller.py`: метод `decide_action` принимает `orderbook_imbalance` и корректирует размер ордера.
- Причина: улучшить реакцию на микроструктуру рынка.

## [2026-05-13] Стабилизация роя и исправление дашборда

### Основные изменения
- `sim/survival_evaluator.py`: либеральные пороги (max_dq=0.2, min_p_liveness=0.5) для активной торговли
- `swarm_config.py`: EXPECTED_RETURN_RATE повышен до 20.0
- `src/evolution/mutation_engine.py`: исправлена подмена параметров LLM; импорт `Event` для записи мутаций
- `src/intelligence/llm_client.py`: fallback генерирует случайные, но разумные параметры
- `dashboard/routes/trades.py`: парсинг side/amount из логов `Leader, swap: ...`
- `mvp/lab_swarm_demo/node_agent.py`: запись `side`/`amount` в события трейда

### Результат
- Рой активно торгует на Sepolia, капитал растёт
- Дашборд корректно отображает все сделки (сторона, объём, символ, хэш)
