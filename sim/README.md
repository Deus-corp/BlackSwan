#Симулятор Swarm-Sim

Минимальная среда для тестирования экономического поведения роя Black Swan. Позволяет моделировать рыночные условия, агентов с различными стратегиями (начиная с Kelly-оптимизации) и собирать метрики.

## Запуск

1. Установите зависимости:
```bash
cd sim
pip install -r requirements.txt
```

1. Запустите базовый сценарий:

```bash
python run.py --config scenarios/basic_economic.yaml
```

Результат — логи и графики в реальном времени.

## Структура

· engine/environment.py — рыночная среда, генерация котировок, волатильность
· engine/agents.py — агенты (Kelly-трейдер, случайный трейдер)
· engine/metrics.py — расчёт и визуализация метрик
· scenarios/ — конфигурационные файлы сценариев в формате YAML
